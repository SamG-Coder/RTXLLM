# Integrated RTX byte predictor

The model archive contains the long-term context surfaces and their sparse next-byte payloads, plus nine copy-gate triangles. Live session state contains the 256-byte geometry ring, cursor, occupied count, model digest and RNG state. Both archives can be reloaded in separate processes. All archives use NumPy arrays without pickle.

For each live prediction the GPU reads the recent bytes from ring geometry. They determine the launch position for the long-term suffix search. Rays in the ring find the longest previous match and its successor. A GPU kernel folds emissions and transmission from the suffix surfaces hit by RTX, measures the selected gate triangle, and emits the 256 next-byte probabilities. Python sequences the dispatches, reads intermediate hits, samples a byte with NumPy and refits the ring. Short prompts start the suffix ray at the deepest layer their history supports. Long-term model fitting uses modified Kneser–Ney; episodic retrieval and learned copy confidence are the additions tested in E9.

## Run

With the repository SlangPy environment on RTX, calibrate the gate once as in experiments/copy_confidence/README.md. Train a long-term scene from independent raw files or use the four pinned E9 books. Use a new output filename for each model and session. The checkpoint writer uses hard links.

~~~sh
python experiments/integrated/model.py build gate.npz model.npz --documents training1.txt training2.txt
python experiments/integrated/model.py score model.npz heldout.txt
python experiments/integrated/model.py generate model.npz session.npz --prompt prompt.txt --seed 53 --count 128
python experiments/integrated/model.py generate model.npz continued.npz --resume session.npz --count 128
~~~

The CLI prints generated bytes as hex for lossless output. Scoring skips the initial eight bytes. Generation accepts any nonempty binary prompt. The training files and calibration archive are only needed for building.

## Reproduce E9

~~~sh
python experiments/copy_confidence/experiment.py calibrate BOOK_DIRECTORY OUTPUT_DIRECTORY
python experiments/integrated/model.py build model.npz OUTPUT_DIRECTORY/gate.npz --help
~~~

To build the pinned model and run the independent check, use the gate as the first positional argument:

~~~sh
python experiments/integrated/model.py build OUTPUT_DIRECTORY/gate.npz model.npz --e9-books BOOK_DIRECTORY
python experiments/integrated/check.py model.npz OUTPUT_DIRECTORY/gate.npz BOOK_DIRECTORY
~~~

On the RTX 5080 the restored archive scored 2.2010866075 bits/byte on all 346,826 E9 test targets in The War of the Worlds. The largest absolute per-target probability difference from the CPU KN plus CPU episodic reference with RTX-read gates was 1.24e-7. The verification checks all 256 probabilities at ten live positions including the first, fourth, 256th and 257th bytes, and exactly reproduces 128 sampled bytes across a fresh-process checkpoint restart.

The four-book model archive occupied 1,769,752 bytes; long-term acceleration structures occupied 10,072,960 bytes. The final verification session occupied 6,398 compressed bytes. One synchronous generation run took 3.04 s for 512 bytes (about 168 bytes/s). One batch score run took 0.376 s, including geometry construction per block, GPU search and decode, transfers and host sequencing, excluding model loading. Timing depends on batching and warmup. The benchmark reproduces the existing E9 result on its test book; it does not constitute a new independent quality trial.
