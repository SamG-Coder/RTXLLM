# Byte mirror pilot

The writer counts adjacent bytes in training text, takes 32 stratified samples per observed context, and aims one triangular mirror per sample. A separate bank of 256 mirrors represents the unigram prior. A checkpoint contains triangle vertices, receiver identities and launch geometry. For each vote, a Vulkan query selects a mirror and a reflected ray intersects a byte receiver. Byte probabilities come from the receiver histogram with 20% unigram interpolation and 1% uniform escape. A context with no hits uses the prior.

Run in the SlangPy environment described in the Vulkan smoke-test README. From the repository root on the development host:

```powershell
$env:VK_LOADER_LAYERS_DISABLE = '~implicit~'
$env:VK_INSTANCE_LAYERS = 'VK_LAYER_KHRONOS_validation'
& "$env:TEMP/rtxllm-vk-env/Scripts/python" -B experiments/byte_mirrors/run.py "$env:TEMP/rtx-byte-first"
& "$env:TEMP/rtxllm-vk-env/Scripts/python" -B experiments/byte_mirrors/generate.py "$env:TEMP/rtx-byte-first/rtx.npz" RTX --count 32 --seed 0
```

The evaluation script reads the pinned Git blobs, splits each document before counting, and resets context at file and split boundaries. It exhaustively traces the 256 possible contexts in one dispatch and scores the resulting distributions on the two reserved splits. The generation command loads the saved geometry, traces the global prior once, then launches 32 new rays for each generated byte. Its first-order context is the last byte of the prefix.

## First run

RTX 5080, driver 616.64, SlangPy 0.43.1. Training used 5,613 bytes of repository prose. Validation and test contained 1,200 and 1,202 scored next bytes. The pilot settings and success criterion are recorded in issue #7.

| Predictor | Validation bits/byte | Test bits/byte |
| --- | ---: | ---: |
| Exact smoothed bigram | 3.8254 | 3.8884 |
| RTX mirror votes | 3.9810 | 4.0447 |
| CPU finite-vote oracle | 3.9810 | 4.0447 |
| Exact smoothed unigram | 4.7259 | 4.7023 |
| RTX unigram | 4.8900 | 4.8602 |
| Shuffled conditional mirrors | 5.5851 | 5.4660 |

All 8,448 ray outcomes matched the CPU writer's expected receiver or miss on each scene. Each scene had 2,688 populated launch slots. The RTX model checkpoint occupied 247,828 bytes and the acceleration structures occupied 184,704 bytes. The finite sampling cost 0.1563 bits/byte against exact bigram counts on this test. Quantization of both conditional and unigram counts contributes to that gap.

This pilot measures one reflection per vote on three short, related documents. It measures neither the incremental benefit of multiple reflections nor a throughput advantage. Generated bytes can be invalid UTF-8. A higher-order predictor requires a new held-out corpus to support a fresh quality claim.
